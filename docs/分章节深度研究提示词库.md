## 第〇部分：使用方法与通用框架

### 0.1 每个提示词的统一结构

本库所有提示词均按五段式构造，您可按同样框架自行扩写新题目：

1. **角色设定**——给 AI 指定一个"比您更专的对话者"身份，迫使其输出专业深度而非科普；
2. **背景注入**——交代您的身份与已有认知水平，避免 AI 输出您已知的常识；
3. **任务分解**——把大问题拆成 5–10 个有逻辑递进关系的子问题（这是深度的来源）;
4. **输出规格**——规定结构、篇幅、证据标注方式；
5. **质量约束**——要求区分"官方定论/行业共识/争议中/个人推断"四个置信层级，标注信息时效，列出一手来源。

### 0.2 通用背景段（每个提示词开头都可粘贴）

```
【我的背景】我是一名有25年临床试验经验的申办方临床负责人，在申办方和CRO均负责过
临床运营、医学、生物统计、质量、注册、非临床和样本检测部门。我不需要基础科普，
需要的是研究生课程级别的深度、监管一手文件级别的准确性，以及只有资深从业者才会
关心的实操细节与争议点。请默认我熟悉ICH基本框架、中美欧注册基本流程和GCP基本要求。
【时效要求】今天是{填写日期}。请优先使用2021年以来的信息，明确标注每条关键信息的
发布/生效时间；对2025年以后仍在演变的事项，说明最新状态和不确定性。
【置信标注】请对每个关键论断标注：[官方定论]/[行业共识]/[争议中]/[你的推断]。
关键事实请给出一手来源（法规编号、指南名称、会议记录、审评报告）。
```

### 提示词 1.1｜质量范式：ICH E6(R3) 与 QbD/RBQM 体系落地

```
【角色】你是一名参与过ICH E6(R3)专家工作组讨论、目前为跨国药企设计RBQM体系的
临床质量科学家，同时深度研究过中国2026版GCP的修订过程。

【任务】为我做一次E6(R3)时代质量体系重构的深度研究，依次回答：

1. 逐条对比E6(R2)与E6(R3)的结构性差异：哪些条款被删除、哪些被"原则化"、
   附件一与附件二的分工逻辑是什么？为什么说这是"重写"而非"修订"？
2. Critical to Quality（CtQ）因素的识别方法论：现有哪些成体系的CtQ识别框架
   （如CTTI的QbD建议、TransCelerate的方法）？给出一个III期肿瘤试验和一个
   医疗器械试验的CtQ识别完整示例。
3. RBQM的技术栈：QTL（质量耐受限度）、KRI（关键风险指标）、中心化监查统计方法
   （如基于分布检验的异常site识别）分别如何设定？给出常用QTL参数库和阈值设定的
   统计学依据。行业主流RBQM软件平台的能力边界在哪里？
4. 中国2026版GCP与E6(R3)的差异点清单：哪些地方中国提出了比ICH更严格/更具体的
   要求（尤其数据治理专章、申办方与PI责任划分）？"不纳入操作细则"的部分给企业
   留下了哪些灵活空间与合规风险？
5. 申办方-CRO合同如何因E6(R3)重写：风险控制可接受范围、CtQ识别责任、数据治理
   责任在合同中应如何条款化？给出关键条款的示范表述。
6. 监管检查的演变：FDA BIMO检查、NMPA药品注册核查在2023-2026年的高频缺陷项
   是什么？E6(R3)实施后检查重点预计如何迁移？
7. 反方观点：E6(R3)的原则化写法受到了哪些批评（如中小企业能力不足、检查标准
   不确定性）？哪些国家/机构的实施口径出现了分歧？

【输出】结构化长文报告；第2、3、5题必须给出可直接使用的模板/示例；最后附
"落地路线图"——一家中型申办方从E6(R2)体系迁移到E6(R3)体系的12步行动清单。
```

## 附：通用追问链与质量校验清单

### A.1 通用追问链（任何一级提示词运行后使用）

按顺序追问，每问一轮深一层：

1. **证据挑战**："你刚才的结论中，证据最薄弱的三个论断是哪几个？分别缺什么证据？"
2. **反方还原**："请扮演最资深的反对者，用最强的论据反驳你自己刚才的核心结论。"
3. **时效压测**："你使用的信息中，哪些可能已经过时？列出需要我人工核实最新状态的事项清单。"
4. **本土折算**："以上结论有哪些隐含了美国/欧洲语境？换到中国申办方的资源与制度环境，哪些要打折扣、哪些反而更有利？"
5. **行动收敛**："如果我只能采纳三个行动，按'影响×可行性'排序应该是哪三个？每个行动的第一步这周就能做的是什么？"
6. **教学检验**："把核心内容压缩成我可以在管理层会议上用10分钟讲清楚的版本（一页纸逻辑+三个金句）。"

### A.2 输出质量校验清单（收到 AI 研究报告后自查）

- [ ] 关键事实是否都有一手来源（法规编号/指南名称/审评报告/会议记录），而非仅媒体转述？
- [ ] 是否区分了"官方定论/行业共识/争议中/推断"四个置信层级？
- [ ] 2025 年以后的信息是否标注了"仍在演变"并给出核实路径？
- [ ] 是否包含反方观点和失败案例，还是通篇顺风叙事？
- [ ] 结论是否可操作（有工具、清单、模板、决策树），还是停留在"应重视、需加强"？
- [ ] 有没有至少一个观点让我感到意外或不适？（如果没有，说明深度不够，运行追问链第 2 问）
