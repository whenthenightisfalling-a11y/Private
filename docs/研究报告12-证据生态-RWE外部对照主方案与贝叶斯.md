## 一、RWE 注册接受度的"真实边界"：三辖区案例清单

### 1.1 先立坐标：RWE 的两种角色

- **关键证据（pivotal）**：RWE 直接承担有效性证明的主体——极少数，且集中在特定场景；
- **支持性证据（supportive）**：补充获益-风险叙事、支持适应症外推、承担对照臂或自然史参照——常态角色。
**误区纠正**：行业常把"FDA 接受过 RWE"泛化为"RWE 可以替代 RCT"——案例清单显示真实边界远比宣传窄。

### 1.2 FDA 实际案例谱系（按角色分级）**[行业共识]**

| 案例 | 年份 | RWE 形态 | 承担角色 | 边界启示 |
|---|---|---|---|---|
| **他克莫司（Prograf）肺移植适应症** | 2021 | 基于美国器官移植登记数据（SRTR）的非干预性研究 | **关键证据**（教科书级先例） | 成立条件苛刻：结局硬（移植物存活/死亡）、登记库覆盖近乎全人群、疾病无替代疗法、药物机制已在其他移植场景确证——四条同时满足的场景极少 |
| **阿培利司（Vijoice）PROS 罕见病** | 2022 | EPIK-P1 回顾性病历审查 | **关键证据**（加速批准） | 超罕见+客观影像终点+单臂回顾性设计被接受——罕见病是 RWE 关键角色的主战场 |
| **哌柏西利（Ibrance）男性乳腺癌** | 2019 | 电子病历/保险理赔/肿瘤数据库 | 支持性（适应症人群扩展） | "生物学同质人群的外推"场景：RWE 补足试验未覆盖人群 |
| **阿巴西普（Orencia）GvHD 预防** | 2021 | 登记库真实世界队列 | 关键证据的组成部分（与临床试验联合） | 登记库质量决定一切 |
| 基因治疗系（Zolgensma、Skysona 等） | 2019– | 自然史队列作外部参照 | 对照角色 | 见第二节外部对照 |

**FDA 边界规律**：RWE 承担关键角色的成立条件=**罕见/无替代治疗 × 硬结局 × 高质量数据源（登记库>病历审查>理赔）× 机制先验强**。四个条件是乘法不是加法——缺一则退回支持性角色。

### 1.3 EMA 与 NMPA **[行业共识+建议复核]**

- **EMA**：条件批准框架下对登记库数据的使用更成体系（罕见病/ATMP 的注册登记作为上市后证据主干）；2022 年起 **DARWIN EU** 网络把"监管发起的 RWD 查询"常态化——欧盟的特色是**监管方自己掌握 RWD 基础设施**，申办方递交的 RWE 会被用 DARWIN 交叉验证 **[建议复核最新覆盖范围]**；JCA 场景下 RWE 用于填补 PICO 缺口（研究报告 06）；
- **NMPA**：制度框架三件套——《真实世界证据支持药物研发与审评的指导原则（试行）》（2020）、《用于产生真实世界证据的真实世界数据指导原则（试行）》（2021）、器械端 RWD 指导原则（2020）及儿童药等场景细则；**海南乐城**是全球独有的"RWD 特区"模式：境外已上市产品在乐城先行使用产生的真实世界数据支持国内注册——器械端已有多个获批先例（首例为青光眼引流器械，2020），药品端持续扩展 **[建议复核最新获批清单]**；粤港澳大湾区"港澳药械通"沉淀类似数据路径；
- **中国边界特色**：乐城模式的本质是"用可控真实世界环境替代重复性注册试验"——适用于**境外证据已充分、仅缺中国人群确证**的产品，与 FDA 的"罕见病缺证据"场景完全不同。**中国 RWE 的最大机会在"外推确证"，美国在"无法做试验"——同一工具、两种定位，出海双报时不可互相照搬论证逻辑。[推断]**

## 二、外部对照：方法学与监管雷区

### 2.1 方法学三件套 **[行业共识]**

1. **目标试验模拟（target trial emulation）**：设计外部对照研究的纪律框架——先写出"假如能做 RCT，方案长什么样"（入排、零时点、干预定义、终点、随访），再让真实世界数据尽可能模拟它。**最大价值是强制暴露"永生时间偏倚"与"零时点错位"**——外部对照最常见的两个致命伤；
2. **倾向评分体系**：匹配/加权/分层把已测混杂拉平——但**只能处理已测量的混杂**，这是它与随机化的本质差距；报告规范要求展示匹配前后的协变量平衡（SMD）与有效样本量损耗；
3. **E 值敏感性分析**：量化"需要多强的未测混杂才能推翻结论"——E 值越大结论越稳健。审评语境下的正确用法是"辅助定量讨论"，不是"未测混杂的赦免券"。

### 2.2 FDA 2023 外部对照试验指南（草案）的红线 **[行业共识]**

- **可比性四轴**：人群（诊断标准、疾病阶段、既往治疗线）、时间（治疗时代效应——十年前的自然史在支持治疗进步后失真，与研究报告 07 的 OPC 漂移同构）、结局判定（试验用 BICR、外部数据用临床记录=系统性不可比）、随访强度（试验密集访视 vs 真实世界稀疏就诊→进展"检出时点"偏差）；
- **程序红线**：外部对照的设计与分析**必须预设**（禁止先看试验结果再选对照集）；须提交**患者层面数据**供 FDA 复核（汇总数据基本不可用）；数据溯源与缺失处理透明。

### 2.3 失败案例的解剖：omburtamab ODAC（2022.10）**[行业共识]**

Y-mAbs 的 omburtamab（CNS/软脑膜转移神经母细胞瘤）以单臂试验+外部历史对照支持 BLA，ODAC 以 **16:0** 认定未能证明对生存的贡献——败因清单几乎是 2.2 节红线的逐条示范：外部对照人群的选择与可比性无法确认、生存差异可被人群构成差异（诊断时代、基线特征、转诊偏倚）完全解释、患者层面可比性分析缺失。**与研究报告 04（信迪利单抗 14:1）并列，构成"证据结构性缺陷在 ODAC 全票/近全票翻车"的双案例——委员会对方法学结构缺陷的容忍度远低于对效应量大小的容忍度。**

### 2.4 决策规则（给方案评审会）

外部对照可行性三问：①该病自然史是否**均质且可预测**（进展快、异质性低）？②效应量预期是否**大到淹没偏倚**（HR 0.9 的药永远不该用外部对照；HR 0.3 可以讨论）？③是否存在**当代、患者层面、结局判定可比**的数据源？三问全"是"才立项，并同步启动前瞻性自然史研究为确证兜底。

## 三、主方案设计的运营真相

### 3.1 三型定义与统计核心 **[行业共识]**

| 类型 | 结构 | 统计核心问题 |
|---|---|---|
| **篮式（basket）** | 一药多瘤种（按生物标志物） | 各篮之间**信息借用**（贝叶斯分层模型）——借多少：借得多则小篮易假阳，借得少则失去篮式意义 |
| **伞式（umbrella）** | 一瘤种多药（按分子分型） | 分型检测的运转时间与多臂多重性 |
| **平台（platform）** | 永续方案、药物进出、常设共享对照 | **非同期对照问题**（后进药物与早期对照的时代错位）、共享对照的 α 管理、适应性随机化 |

### 3.2 三个原型案例的运营真相 **[行业共识]**

- **I-SPY2**（乳腺癌新辅助平台）：贝叶斯适应性随机化+"毕业"机制（药物达到预设成功概率即毕业进入注册路径）——**证明了平台可以作为 II 期引擎持续产出**；运营真相：学术联盟主导+多家药企供药的治理结构，磨合成本极高，药企对数据权与发表权的谈判是隐形瓶颈；
- **RECOVERY**（英国新冠平台）：极简务实设计（超简 eCRF、常规医疗数据承载终点、全英 NHS 站点网络）——**地塞米松结果改写全球治疗、成本只有传统试验零头**；运营真相：成功前提是 NHS 单一体系+国家层面的预置授权——**可复制的是"极简主义设计哲学"，不可复制的是英国的体系条件**；
- **中国实践**：肿瘤领域多家申办方与研究者网络已运行伞式/篮式研究，监管端适应性设计指导原则（2021）已就位、主方案专项技术要求在持续完善 **[建议复核 CDE 最新文件状态]**；运营短板与国际同构——多申办方共享平台的合同/数据权治理，以及机构伦理对"永续方案+滚动修订"的审查机制适配。

### 3.3 三层决策清单（立项前必答）

- **统计层**：共享对照的时代效应处理预案？信息借用的先验强度由谁批准？平台整体 α 的监管沟通口径？
- **运营层**：药物供应的多申办方协调（各药各自的温控/效期/召回路径在同一方案下并行）；每次新增子方案的合同增补时长（行业痛点：法务周期>科学周期）；中心实验室分型的 TAT 是否撑得起入组节奏；
- **监管层**：主方案的 IND/CTA 架构（母方案+子方案的递交层级）、每个子研究能否独立支撑注册声明、DSMB 对全平台的统一监察章程。**主方案失败的第一大原因不是统计，是治理——没有明确"谁有权让一个臂关门"的平台必然在利益冲突中瘫痪。[行业共识+推断]**

## 四、贝叶斯方法的制度化进程

### 4.1 制度里程碑 **[行业共识]**

- **ICH E11A 儿科外推**（2024 Step 4）：把"成人→儿科的信息借用"制度化——贝叶斯从"可选方法"升格为"外推框架的默认载体"；
- **FDA 复杂创新设计（CID）试点**（2018 起）：为贝叶斯/适应性设计提供加深沟通通道，积累了公开案例集（含贝叶斯借用历史对照获同意用于关键试验的先例）；器械端（CDRH）贝叶斯传统更久（2010 指南）；
- **常用借用机制**：power prior（历史数据打折扣纳入）、commensurate prior（按历史与当前数据的一致程度动态调权）、robust MAP prior（元分析预测先验+稳健成分）——共同思想：**借用强度不是拍脑袋，而是"历史与当前的一致性"的函数，且必须预设并做动态削权保护**；
- **CDE 态度**：适应性设计指导原则（2021）明确接纳贝叶斯要素；罕见病与儿科场景的沟通中对借用持开放态度，但要求**模拟研究证明 I 类错误特性**——与 FDA 口径一致。**[行业共识]**

### 4.2 管理者的三个把关问题

①先验从哪来、打了几折、谁批准的？②如果历史数据与当前试验冲突，模型会自动"松手"吗（动态借用）？③模拟研究覆盖了多少种"历史误导当前"的情景，最坏情景的 I 类错误膨胀到多少？——三问答不清的贝叶斯方案，是把方法学时髦当遮羞布。

## 五、MIDD：模型引导的药物研发的边界

**已成熟的替代场景 [行业共识]**：PBPK 模型替代部分 DDI 临床研究（已写入标签的常规操作）；暴露-效应分析支持未直接试验的剂量获批（尤其调整剂量）；成人→儿科的 PK 外推豁免儿科疗效试验（配合 E11A）；生理模型支持特殊人群（肝肾损伤）剂量建议替代专门研究。

**边界所在**：MIDD 能替代的都是"**机制链条清晰+终点与暴露强关联**"的问题；它不能替代的是效应本身的存在性证明——**模型可以告诉你剂量选对没有，不能告诉你药有没有用**。FDA MIDD 配对会议试点提供了逐案锁定边界的通道 **[建议复核试点最新状态]**。

**与研究报告 11 的连接**：在"单试验+确证性证据"框架下，MIDD 产出（暴露-效应、机制模型）恰是"确证性证据"清单上的正式成员——把建模团队纳入注册策略会，是零成本的证据增产。

## 六、综合演练：罕见病基因治疗的证据组合设计

**场景**：某 AAV 基因治疗，靶向超罕见神经退行性单基因病（全球确诊约 3,000 例，儿童起病，2–4 年进展至丧失行走能力，无获批治疗）。RCT 不可行（人数+伦理+家长拒绝随机）。以下为完整证据组合设计：

```
┌────────────────────────────────────────────────────────────┐
│            证据组合架构（每块标注其监管角色）                │
├────────────────────────────────────────────────────────────┤
│ ① 前瞻性自然史研究（立项第一天启动，先于治疗试验）          │
│    角色：外部对照的数据源 + 终点开发的基础 + 确证性证据      │
│    设计要点：与未来治疗试验使用相同的入排/评估量表/访视      │
│    频率/中心实验室——"为可比性而设计"（目标试验模拟前置）；  │
│    患者层面数据协议预先约定可递交监管                        │
│ ② 单臂关键试验（N≈25–35）                                   │
│    终点：运动功能量表变化（与自然史可比）+ 生物标志物         │
│    （转导效率/蛋白表达——机制证据）                          │
│    对照：①的同量表匹配队列；预设倾向评分+E值敏感性分析       │
│ ③ 剂量依据：MIDD 包（动物剂量转换模型+首例队列的暴露-        │
│    表达-功能三级关联）——回应 Optimus 式追问                 │
│ ④ 贝叶斯借用：若存在同载体/同给药途径的前款产品安全性        │
│    数据库，用 robust MAP prior 增强安全性数据库的解释力      │
│ ⑤ 确证性证据包（对接研究报告 11 第三节清单）：               │
│    机制证据（基因-蛋白-表型链条）+ 病理生理学 + ①的剂量       │
│    外情景 + 国际登记库的流行病学一致性                       │
│ ⑥ 上市后：注册登记研究（15 年随访义务）+ 支付端的疗效         │
│    挂钩协议数据流（对接研究报告 06 第 1 讲 CGT 支付创新）     │
├────────────────────────────────────────────────────────────┤
│ 监管沟通节奏：pre-IND 锁定"①作为对照的可接受性"书面意见 →    │
│ II 期结束会议锁定"单臂+外部对照+确证包"的充分性 →            │
│ （美国）RDEP/合理机制路径适配性评估（研究报告 11）→          │
│ （中国）罕见病通道+附条件批准的确证性研究预设（研究报告 02） │
├────────────────────────────────────────────────────────────┤
│ 反脆弱三问（对照研究报告 07 画布 G 区）：                    │
│ · 若②效应量低于预期：①的数据颗粒度够做亚组挽救分析吗？      │
│ · 若审评质疑自然史时代效应：①是前瞻同期的——这正是第一天     │
│   就启动它的原因                                             │
│ · 若被要求随机对照：延迟治疗设计（全部入组、随机分期给药）    │
│   是预置的 Plan B 吗？                                       │
└────────────────────────────────────────────────────────────┘
```

**本演练的可迁移原则**：①**自然史研究是罕见病资产的第一笔投资**，晚于治疗试验启动的自然史研究价值折半（同期性丧失）；②每块证据入场时就写明"监管角色"，避免"数据很多、论证没有"的堆料式递交；③Plan B（延迟治疗随机设计）在设计期预置的成本极低，被动补做的成本极高。
